Overview:

This page demonstrates knowledgebase and playbook integration using the AllKQLtoHTML PowerShell utility.

Summary:

Below are several common methods for generating KB and playbook links.

  1. If you were directed here from the first link on the sample page, that rule used an explicit URL loaded directly from the CSV file.
  2. In most environments, the script can automatically generate KB links directly from the rule name without using the CSV file, ie: "mywiki.com/rule-name".
  3. You can also append a suffix to generated links, such as ".html", if your KB platform requires it, ie: "mywiki.com/rule-name.html".
  4. Another option is to generate anchor links so multiple rules can share the same page. The remaining rules on the sample page use this method to direct you here using anchors. Even if the anchor doesn't exist, as long as the BaseUrl does, the links will work, ie: "https://schvenn.github.io/AllKQLtoHTML/sample_kb.html#some-rule-name".
  5. Instead of linking directly to pages, the script can also generate KB search URLs using the rule name as the search query, ie: "https://company.service-now.com/sp?id=search&spa=1&t=kb&q=some%20rule%20name".

As shown above, the script supports multiple KB integration methods, including direct CSV mappings, generated links, anchor links, and search-based URLs. CSV mappings and script generated links can also be used together in a hybrid configuration.

Curl downloading a script file

Captures curl activity that involves downloaded executable script files, which is unusual in any corporate environment.

Enabled: ✅ true
Severity: 🔴 High

// Curl dowloading a script file.
let ScriptExtensions = dynamic([".bash", ".bat", ".cmd", ".hta", ".js", ".jse", ".ksh", ".p1", ".php", ".ps1", ".psd1", ".psm1", ".py", ".rb", ".sh", ".vbe", ".vbs", ".wsf", ".wsh", ".zsh"]);
let DownloadProtocols = dynamic(["ftp://", "ftps://", "http://", "https://", "sftp://"]);
union(SecurityEvent
| extend CommandLine = tolower(CommandLine), NewProcessName = tolower(NewProcessName)
| where EventID == 4688 and NewProcessName endswith @"\curl.exe" and CommandLine has_any (DownloadProtocols) and CommandLine has_any (ScriptExtensions)
| project TimeGenerated, Device = Computer, Account = SubjectUserName, ParentProcess = ParentProcessName, Process = NewProcessName, CommandLine = CommandLine, Source = "SecurityEvent"),
(DeviceProcessEvents
| extend ProcessCommandLine = tolower(ProcessCommandLine), FileName = tolower(FileName)
| where FileName =~ "curl.exe" and ProcessCommandLine has_any (DownloadProtocols) and ProcessCommandLine has_any (ScriptExtensions)
| project TimeGenerated, Device = DeviceName, Account = AccountName, ParentProcess = InitiatingProcessParentFileName, Process = FileName, CommandLine = ProcessCommandLine, Source = "DeviceProcessEvents")
| order by TimeGenerated desc
