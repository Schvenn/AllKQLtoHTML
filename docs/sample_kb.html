Summary:

Here are a few tips for using the KB generator.

  1. If you were directed here from the first link on the sample page, you will see that it went to an explicit URL for this page. That's because there is an entry in the CSV file for that first rule.
  2. In most cases however, you will have a wiki or knowledgebase setup on which you create pages for each rule name. For those rules, you won't use the CSV file. Instead, you will let the script create a link based on the rule name. Usually, this would be something like "mywiki.com/rule-name". Simply set the BaseUrl in the PSD1 configuration file and let the script generate the page name that appends to it.
  3. Of course, you can also use the Suffix option, as necessary. That would be similar to the previous configuration, but perhaps you need a ".html" extension on the end. So, the generated link might instead look like "mywiki.com/rule-name.html"
  4. If you want to use the same page for multiple rules, you can also use a parent page and let the script generate an anchor link, which is what happens for the remaining rules on the sample rules page. They all direct to "https://schvenn.github.io/AllKQLtoHTML/sample_kb.html#some-rule-name". Since the parent page exists, the redirection works, regardless of whether or not the anchor exists. This is another fallback option.
  5. The final tip I have is to use the script to generate a search link, instead of a direct page link. If your knowledgebase was ServiceNow for example, you could let the script generate a link like this: "https://company.service-now.com/sp?id=search&spa=1&t=kb&q=some%20rule%20name", wherein the BaseURL would include everything up to the "q=" portion or the URL, and the search query would be created by the script for the remainder of the URL. In this case, you would set the Separator option in the PSD1 file to "html", so that the script replaces characters in the DisplayName to work properly with most search engines.

As you can see, there are many ways to make the link generation work, for nearly every environment, even mixing the CSV file and link generator, at the same time, in the same environment.

The rest of this page is a knowledgebase format example for demonstration purposes only.
